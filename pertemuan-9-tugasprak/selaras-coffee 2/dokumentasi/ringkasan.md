# Ringkasan Tugas Individu – Website Selaras Coffee

Nama : Muhamad Rasha Zein
NPM  : 4525210042

Pada tugas ini saya membuat website one page untuk UMKM Selaras Coffee menggunakan Bootstrap 5.3.8 melalui CDN. Saya mengembangkan contoh grid dan card dari modul menjadi satu halaman utuh berisi navbar responsif, hero section, tiga card produk, alert promo, modal detail produk, form kontak, dan footer. Agar tidak terlihat seperti template bawaan, saya menambahkan custom CSS berupa palet warna kopi dan krem, font Playfair Display untuk judul, serta efek hover pada card.

Masalah yang saya temukan ada tiga. Pertama, navbar fixed menutupi judul section saat menu diklik. Kedua, tinggi card tidak sama sehingga grid terlihat berantakan. Ketiga, form kontak bisa terkirim dalam keadaan kosong.

Solusinya, saya menambahkan scroll-margin-top pada section, memakai class h-100 pada card, dan memakai atribut required serta type="email" bawaan HTML5 sehingga form tidak bisa dikirim jika masih kosong. Saya juga mengatur breakpoint col-12 col-md-6 col-lg-4 agar tampilan menyesuaikan layar HP, tablet, dan desktop.

Seluruh kode saya kerjakan sendiri dan siap saya jelaskan saat presentasi.

Catatan pembagian peran: tugas individu, tidak ada pembagian peran.
